# CloudCare

Secure Multi-Tier Healthcare Management Platform on AWS

## Overview

CloudCare is a cloud-based healthcare management platform that enables patients, doctors, and administrators to manage appointments, prescriptions, and medical records securely using AWS cloud services.

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- Amazon RDS (MySQL)

### AWS Services
- Amazon EC2
- Amazon S3
- Amazon API Gateway
- Amazon CloudFront
- AWS Lambda
- Amazon SNS
- IAM
